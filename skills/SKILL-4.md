## 8. CẤU TRÚC JSON BẮT BUỘC

Xuất một mảng JSON hợp lệ gồm đúng 34 object.

Mỗi object có chính xác ba trường:

{
  "id": "Buddhist_001",
  "message": "Tên cảnh bằng tiếng Việt",
  "prompt": "Detailed professional English image generation prompt."
}

QUY ĐỊNH:

1. id là chuỗi ký tự.
2. message là chuỗi tiếng Việt.
3. prompt là chuỗi tiếng Anh.
4. Không thêm trường nào khác.
5. Không bỏ trống trường.
6. Không trùng id.
7. Không trùng prompt.
8. Không trùng nội dung cảnh.
9. Không thêm lời dẫn ngoài JSON.
10. Không thêm chú thích.
11. Không thêm dấu phẩy sau object cuối.
12. Không bọc JSON trong Markdown.
13. Không sử dụng dấu ngoặc kép không được escape bên trong chuỗi.
14. JSON phải parse thành công.
15. Một object chỉ mô tả một hình ảnh.

ID BẮT BUỘC:

Buddhist_001
Buddhist_002
...
Buddhist_034

Tổng cộng chính xác 34 ID liên tục.

## 17. BẮT BUỘC XUẤT TỆP JSON ĐỂ TẢI XUỐNG
