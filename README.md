## 📌 HƯỚNG DẪN 4 BƯỚC ĐƯA LÊN GITHUB ĐỂ TẠO TRANG WEB (GITHUB PAGES)

Trang web đã được thiết kế sẵn tệp **`index.html`** tự chứa toàn bộ giao diện, hình ảnh, âm thanh, video động lực và bộ 4 kỹ năng tải về mà không cần cài đặt thêm bất kỳ phần mềm nào.

Anh/Chị chỉ cần làm theo 4 bước cực kỳ đơn giản sau:

### BƯỚC 1: TẠO KHO LƯU TRỮ MỚI TRÊN GITHUB (REPOSITORY)
1. Truy cập vào trang web [GitHub.com](https://github.com/) và đăng nhập tài khoản của anh/chị.
2. Bấm vào nút **"New"** (hoặc dấu **`+`** ở góc phải trên cùng chọn **"New repository"**).
3. Đặt tên kho lưu trữ tại mục **Repository name** (Ví dụ: `giao-an-video-phat-giao` hoặc `video-phat-phap-muse-ai`).
4. Tại mục phạm vi, chọn **Public** (Công khai để mọi người có thể xem web).
5. Bấm nút xanh **"Create repository"** ở phía dưới cùng.

### BƯỚC 2: TẢI TẤT CẢ CÁC TỆP TRONG FILE ZIP NÀY LÊN GITHUB
1. Giải nén file `.zip` này ra một thư mục trên máy tính của anh/chị.
2. Tại giao diện GitHub vừa tạo xong, bấm vào dòng chữ **"uploading an existing file"** (hoặc nút **Add file** -> **Upload files**).
3. Kéo toàn bộ các tệp trong thư mục vừa giải nén (gồm `index.html`, `README.md`, `.nojekyll`, các file `SKILL-1.md`, `skill-2.yaml`, `SKILL-3.md`, `SKILL-4.md`...) và thả vào khung tải lên của GitHub.
4. Chờ GitHub tải lên xong 100%, kéo xuống dưới và bấm nút xanh **"Commit changes"**.

### BƯỚC 3: KÍCH HOẠT TÍNH NĂNG GITHUB PAGES
1. Bấm vào tab **Settings** (biểu tượng bánh răng) ở thanh menu trên cùng của repository.
2. Ở cột menu bên trái, tìm và bấm vào mục **Pages** (trong phần *Code and automation*).
3. Tại mục **Build and deployment** -> **Branch**:
   - Chuyển từ `None` sang chọn nhánh **`main`** (hoặc `master`).
   - Thư mục giữ nguyên là **`/(root)`**.
4. Bấm nút **Save**.

### BƯỚC 4: LẤY ĐƯỜNG LINK TRANG WEB HOÀN CHỈNH
1. Chờ khoảng 1 đến 2 phút để GitHub tiến hành xuất bản website.
2. F5 tải lại trang mục **Pages**, anh/chị sẽ thấy dòng chữ thông báo màu xanh:  
   *"Your site is live at `https://<ten-tai-khoan>.github.io/<ten-repository>/`"*
3. Bấm vào đường link đó để truy cập trang web hoặc sao chép gửi cho Thầy Tuấn và anh chị em lớp học cùng chiêm ngưỡng!
